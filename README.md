# RangeFinder
Functional ultrasonic range finder from concept to completion, including schematic design, component selection, prototyping, and microcontroller programming (MSP430). Integrated an LCD display and an ultrasonic sensor for real-time distance measurement with +/- 1cm accuracy

## This Repository includes:
 - Schematic File (Fusion 360)
 - PCB Layout File (Fusion 360)
 - Necessary external Fusion 360 library
 - MSP430 Microcontroller code for the Range Finder
 - Demo Video of the prototype
